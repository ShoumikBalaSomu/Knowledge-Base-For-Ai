# UI UX Design and Human Psychology Guide

## Overview
Create engaging interfaces through human psychology.

## Psychological Principles
- Hicks Law: Fewer choices = faster decisions
- Fitts Law: Larger targets = easier to hit
- Gestalt Principles: Group related items

## Visual Hierarchy
- Clear typography scale
- Color psychology
- Contrast ratios (4.5:1 minimum)

## Checklist
- Accessibility (WCAG 2.1 AA)
- Performance (Core Web Vitals)
- User feedback system
- Responsive design
