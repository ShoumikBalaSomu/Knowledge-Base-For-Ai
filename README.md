## Quick Start

### For Humans
1. Read the files in order (01 to 05).
2. Use the checklists at the end of each file.
3. Adapt - don't blindly copy. Context matters.

### For AI Agents
Paste this into your system prompt before any task:

    You must follow the knowledge base in this repository.
    Before writing ANY code, read and internalize all 5 files.
    Apply every applicable rule. Cite the file and section.
    Never skip security or accessibility.

## Security Philosophy

- Every secret encrypted at rest AND in transit
- Zero-Trust: no component trusts another by default
- Quantum-resistant algorithms (CRYSTALS-Kyber, CRYSTALS-Dilithium, SPHINCS+)
- No secrets in source code - ever
- Automated dependency scanning on every commit
